# nifiplayer

موزیک پلیر مدرن اندروید که به‌صورت خودکار فایل‌های صوتی گوشی را پیدا و نمایش می‌دهد.

## امکانات
- شناسایی خودکار فایل‌های صوتی از MediaStore
- پخش، توقف، قبلی و بعدی
- پخش تصادفی (Shuffle) و تکرار (off / all / one)
- تم روشن و تاریک
- لوگوی اختصاصی

## ساخت APK با GitHub Actions
1. این پوشه را در یک ریپوی گیت‌هاب push کن.
2. از تب **Actions** workflow با نام `Build nifiplayer APK` را انتخاب کن.
3. روی **Run workflow** بزن.
4. APK نهایی در بخش **Artifacts** همان اجرا قابل دانلود است.

## نکته
پوشه‌ی `android/` اگر در ریپو نباشد، workflow آن را خودکار با `flutter create` می‌سازد.
